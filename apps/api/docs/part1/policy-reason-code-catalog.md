# Policy reason-code catalog

## Scope and evidence

- SCOPE_INCOMPLETE_REQUIRES_REVIEW: required catalog coverage is not complete.
- MATCH_FOUND_WITH_INCOMPLETE_SCOPE_REQUIRES_REVIEW: positive evidence remains visible,
  but omitted/failed references prevent automatic permission.
- SCAN_ERROR_REQUIRES_REVIEW: the evidence pipeline failed.
- VISUAL_EVIDENCE_INCONCLUSIVE: the strongest copy candidate reached review, not match.
- NO_MATCH_IN_DECLARED_CATALOG: no supported match in the complete declared catalog.
- PASS_IS_POLICY_NOT_COPYRIGHT_CLEARANCE: mandatory boundary on that narrow pass.

Coverage-specific reasons such as REQUIRED_LEARNED_RETRIEVAL_INCOMPLETE,
CANDIDATE_VERIFICATION_TRUNCATED, CANDIDATE_VERIFICATION_FAILURE, and
COVERAGE_MANIFEST_INCONSISTENT are appended without being hidden.
