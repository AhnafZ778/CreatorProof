## Asset freeze checklist

For each scenario, the project owner must replace the placeholder with:

- durable asset ID and SHA-256;
- owned, commissioned, licensed, public-domain verified, or written authorization;
- permission reference and allowed competition/publication use;
- source-lineage ID and any transform recipe;
- demo exposure status;
- expected packet fragment captured from the locked bundle;
- a fallback presentation if an optional provider is unavailable.

Until every row has that record, the scenario package is suitable for software
contract verification but not a claim of lawful demo-corpus completion.
